# Ch2: Representing and manipulating information

**The story of the chapter:** everything is bits, and meaning comes from how the bits are read (§2.1). Integers have two encodings, unsigned and two's complement (§2.2). Fixed width makes integer arithmetic wrap around (§2.3). Floating point trades exactness for range (§2.4).
