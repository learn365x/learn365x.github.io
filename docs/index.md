## How each point works
The same for every topic:

1. **Questions first**: answer without reading anything.
2. **If stuck**: read the exact section of the source, then re-answer.
3. **Predict, then run**: write down the expected output before running the code test.
4. **Summary**: in my own words.
5. **Big picture**: the same principle in other fields.
6. **Mistakes log**: what I got wrong, and why.

Status of each point: `seen` → `can answer` → `can apply`.

## Rules
- At most 2–3 active topics at once.
- Questions and answers are checked by running code.
- Point IDs start with the topic, e.g. `csapp-2-01`.
- No solutions to official course labs in this public repo.
- 80% learning, at most 20% writing pages.
