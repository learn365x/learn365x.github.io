# learn365x.github.io

Learning from first principles, one point at a time. Site: <https://learn365x.github.io>

- `ROADMAP.md`: the context file: method, rules, topics, where things stand
- `docs/index.md`: overview of all learning lines
- `docs/<area>/<topic>/index.md`: each topic's own roadmap, point list and log
- `docs/template.md`: page formats and rules
- `labs/`: my own small labs

## Run locally
    pip install -r requirements.txt
    mkdocs serve        # http://127.0.0.1:8000
